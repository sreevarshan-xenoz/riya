# Riya v0.1 Sprite Pack Implementation Plan (plan 3 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce Riya's 2D sprite pack: one outfit, 14 expressions, each with mouth closed, mouth open and eyes closed,
as transparent PNGs, in the Alya style of `riya images/`, plus a manifest that the body (plan 2) loads.

**Architecture:** Generation runs on a free Colab T4. A pack builder runs on the laptop CPU. To keep her consistent, one
full-figure base image is generated in the chosen outfit, and every expression and variant is made by **inpainting only
the face region** of that base, so her body, outfit and pose never drift. `covering_eyes` is the one exception: it also
inpaints the hands and upper arms. The builder removes backgrounds, normalises the canvas, writes the manifest and
validates it against the body's schema.

**Tech Stack:**
- Colab: diffusers (SDXL) with the anime checkpoint `cagliostrolab/animagine-xl-3.1`, IP-Adapter
  (`h94/IP-Adapter`, `sdxl_models/ip-adapter-plus_sdxl_vit-h.safetensors`) and an optional Alya character LoRA.
- Laptop: `rembg` (the `isnet-anime` model), Pillow, `jsonschema` and pytest.

**Spec:** `docs/superpowers/specs/2026-10-18-riya-v0.1-she-missed-you-design.md` (section 6.6)

**Depends on:** plan 2, Task 2 (`body/sprite-manifest.schema.json`, and the expression list in
`docs/protocol.schema.json`). This plan can start before the core is finished.

## Global Constraints

- The reference images, the LoRA, every generated image and the final pack never get committed. The outputs go to
  `sprites/` (gitignored) locally and to `MyDrive/jarvis/sprites/` on Colab. Only the scripts and tests are committed.
- There's one outfit, chosen by the user from the candidate sheet (Task 1). There are exactly the 14 expressions in
  `docs/protocol.schema.json`, each with the variants `closed`, `open` and `blink`.
- The pack canvas is 768×1344, a transparent full figure. `crops.upper` frames the head and shoulders for the panel mode.
- Colab work must survive session loss: every script skips outputs that already exist and can be re-run (this follows
  the "keep everything resumable" lesson in `RESUME.md`).
- The LoRA is optional and supplied by the user (a `.safetensors` path argument). Without it, the reference images guide
  her look through IP-Adapter alone.
- Character rights: private use only (spec, section 4). Swapping the art later means re-running this pipeline with
  different references.

## Review Focus

1. **Identity drift between expressions** (a different face shape or eye colour). The face-only inpaint and a fixed seed
   per expression keep it consistent. The review sheet (Task 2) makes drift visible before the pack is built.
2. **Background removal eats silver hair against a white background.** Use `isnet-anime`, generate on a mid-grey
   background (`#808080`), and keep alpha matting on. Pinned in Task 3 by the edge test and the review sheet.
3. **A partial pack after a Colab disconnect.** The builder lists what's missing, the body falls back per frame, and
   regenerating only the missing parts is possible with `--only`. Pinned in Task 3.
4. **Different sizes and offsets between variants.** The builder pastes every frame onto the same 768×1344 canvas at the
   same anchor, so swapping frames never makes her jump. Pinned in Task 3.

### Task 2: The base figure and face-inpainted expressions

**Files:**
- Create: `colab/sprites/gen_expressions.py`
- Modify: `tests/test_sprite_pack.py`

**Interfaces:**
- Consumes: `common.py`, and `sprites/choice.json` (uploaded to Drive).
- Produces:
  - `face_box(width, height, override: tuple | None) -> tuple[int, int, int, int]`. It's a fixed box covering the head
    for the 832×1216 base, `(256, 60, 576, 420)`, unless `--face-box x0,y0,x1,y1` is given after the user looks at the
    base image.
  - `job_list(expressions, variants, existing: set[str]) -> list[tuple[str, str]]` returns the `(expression, variant)`
    pairs whose `<expr>_<variant>.png` isn't in `existing`, in protocol order.
  - `gen_expressions.py --choice choice.json --refs <dir> --out <dir> [--lora ...] [--only pouty,sad] [--face-box ...]`
    does the following:
    1. Generates `base.png` once, with the chosen outfit and seed, `neutral` and `closed`, on a `#808080` background.
    2. For each job, inpaints the face box using the SDXL inpaint pipeline built from the same checkpoint, with strength
       0.55, the prompt `BASE_PROMPT + outfit + expression + variant`, and the seed
       `hash(expression) % 10000 + seed`, which is stable across runs.
    3. For `covering_eyes`, also inpaints a hands mask: the face box extended down by 280 px, at strength 0.75.
    4. Skips files that already exist.
    5. Writes `review_sheet.png`, a grid of 14 rows × 3 columns.

### Task 3: Building and validating the pack

**Files:**
- Create: `colab/sprites/build_pack.py`
- Modify: `tests/test_sprite_pack.py`

**Interfaces:**
- Consumes: the raw frames from Task 2, `body/sprite-manifest.schema.json` and `docs/protocol.schema.json`.
- Produces:
  - `normalise(img: Image.Image, canvas=(768, 1344)) -> Image.Image` scales the image to fit inside the canvas
    (`min(canvas_w / w, canvas_h / h)`, keeping the aspect ratio), then pastes it bottom-centred onto a transparent
    canvas. The same transform applies to every frame.
  - `build_pack(raw_dir: Path, out_dir: Path, remove_bg: Callable[[Image.Image], Image.Image], name="riya-v1") -> list[str]`:
    1. Processes every `<expr>_<variant>.png` it finds.
    2. Writes `out_dir/<expr>_<variant>.png` and `out_dir/manifest.json`. The upper crop is computed from the face box (`face_box(832, 1216, args.face_box)`
       from `gen_expressions`, which must not import diffusers at module level) scaled into canvas coordinates, extended down by 40% of the canvas height and clamped.
    3. Validates the manifest against the body schema with `jsonschema` and returns the list of missing
       `<expr>.<variant>` names.
    4. Raises `ValueError` if `neutral_closed.png` is missing.
  - `default_remover()` returns a function using `rembg.new_session("isnet-anime")` with
    `alpha_matting=True`.
  - CLI: `python colab/sprites/build_pack.py --raw <dir> --out sprites/riya-v1` prints any missing frames.

from colab.sprites.build_pack import build_pack, normalise


def fake_remove(img):
    img = img.convert("RGBA")
    px = [(r, g, b, 0 if (r, g, b) == (128, 128, 128) else 255) for r, g, b, _ in img.getdata()]
    img.putdata(px)
    return img


def frame(color):
    im = Image.new("RGB", (832, 1216), (128, 128, 128))
    im.paste(Image.new("RGB", (200, 900), color), (316, 316))
    return im

    assert a.size == b.size == (768, 1344)
